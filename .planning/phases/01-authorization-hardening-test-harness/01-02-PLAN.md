<objective>
Stand up the project's first automated test suite (Vitest) and use it to convert the Plan 01-01 authorization fixes — plus the already-correct per-user isolation logic — into CI-guarded invariants. This is the deliverable that makes a future dropped `userId` filter or removed admin gate fail loudly instead of silently shipping.

Two test styles, per the locked strategy:
- Pure auth-gate tests (mock only `@/auth`, no DB): prove the 401/403 gates on /api/scan and every admin route (AUTHZ-01, AUTHZ-04).
- Isolation tests against a real ephemeral SQLite file (temp path, `prisma migrate deploy`, two seeded users): prove the `userId` filter genuinely blocks cross-user access (AUTHZ-03, TEST-02), including the progress/recent fix from Plan 01-01.

Purpose: TEST-01/02 fold into the security phase precisely so the fixes ship with their regression tests, not after.
Output: a `vitest.config.mts`, a `test` script, two helper modules, a setup file, and two spec files. Authored and committed here; **run green on the host** (host/VM split — `npm install`, `npm test`, `prisma migrate` cannot run in the agent environment).
